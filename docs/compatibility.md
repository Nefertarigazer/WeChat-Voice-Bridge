# 微信 4.2 与 Windows 兼容性

| 对象 | 结论 |
| --- | --- |
| 本机 OS | Windows 11 家庭中文版 x64，Build 22631。 |
| 本机微信 | 运行中的 `Weixin.exe` 文件版本为 **4.2.0.53**。密钥提取与只读协议链路已在该版本上实测：主进程候选密钥（70 个）对本机账号的 26 个数据库**全部通过 page1 HMAC 校验**（26/26），`contact.db`、4 个消息分片结构、zstd 解压、引用回复及 worker `browse`/`wechat` 协议闭环均正常；完整扬声器监听链路曾在 **4.2.0.13** 与 **4.2.0.52** 上做过。 |
| 微信 4.2.0.13 / 4.2.0.52 | 实机版在已选一对一会话完成新消息监听、合成和 Windows 播放（4.2.0.52 另经全链路 GUI 复验）。 |
| 微信 4.2.0.11 | 上游 README 记载该版本的实机验证，本项目未复测。 |
| 微信真实监听 | 支持范围 **4.1.11 至 4.2.0.53**，其中 4.2.0.13、4.2.0.52、4.2.0.53 已实测（三个版本的 Config.Cipher 布局、XOR 掩码与各偏移一致）。限制在明确配置的账号和单一会话，仅处理新入站普通文字。分片集合变化或微信进程重启时要求重新开始。 |
| 版本不受支持时的提示 | 主窗口先打开，再异步确认语音桥有没有新版本，然后才弹提示框（不阻塞启动）。框内主按钮是「更新语音桥」，点后在框内检查、下载并重启安装；提示会区分“更新语音桥即可解决”“已发布但仍不支持”“已是最新、新版微信正在适配中”三种情形。「更新微信」只在微信低于 4.1.11 时出现；高于 4.2.0.53 时不出现，只说明正在适配。点右上角 × 关闭提示框就是退出应用，但已点「更新语音桥」或「更新微信」之后关闭则不退出。线上清单固定为 6 字段，缺失支持区间字段时默认「有新版本就提供更新入口」。 |
| 模拟 Worker | Windows x64 Python 3.12.10，SQLite 3.49.1。固定合成账号 `demo-local` 和一对一会话 `demo-peer`。 |
| WPF 发布 | `win-x64` 自包含发布，含独立的 Python 3.12 Worker 运行时。 |

上游版本依据见 [v1.2.9 中文 README](https://github.com/fanyuantaier/wechatauto-replica/blob/bc2e6f2461330eb1a53996d2f2afc18416376b52/README.zh-CN.md)。

本机结果见 [单会话实机报告](wechat-live-test.md)。其他微信版本及无需重启的分片轮换仍待验证。
