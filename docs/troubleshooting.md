# 排障与已知限制

| 情况 | 处理 |
| --- | --- |
| 找不到真实微信会话 | 核对运行中的微信版本为 4.2.0.13，确认已登录并填写了所选账号目录及联系人 ID。 |
| 「正在准备」 | 等待「正在监听」。如遇 Worker 或配置错误，界面显示原因，可重置后手动重试。 |
| Python Worker 缺失 | 完整解压发布目录，或在开发模式创建 Python 3.12 x64 虚拟环境。 |
| Fish 401 / 403 / 402 | 核对 API Key、私有音色授权及余额。Drama 3 余额不足时可在会话页切回免费档。 |
| Fish 429 / 5xx | 每条最多初次请求加两次退避重试。长于五秒的服务端等待要求会停止当条尝试，并在当前合成实例内抑制后续请求直到等待结束。 |
| PCM 没有输出或报格式错误 | 关闭实验性 PCM，重新开始或试音以使用完整 MP3。 |
| 输出设备断开 | 显式设备 ID 保留，后续消息会重新尝试打开该设备。需要切换设备时先结束会话。 |
| 应用最小化后不在任务栏 | 从托盘选择「显示窗口」。托盘同时提供停止和退出。 |
| 异常退出后遗留会话缓存 | 重开应用后仍为 IDLE。在设置页运行「清理会话缓存」。 |

## 尚需验证

- 微信客户端升级及动态新增分片后的持续读取。当前适配器检测到分片集合改变后要求重启监听。无法按 UTF-8 解码的消息会被跳过。
- Drama 3 的真实合成与音质对比。应用支持已创建的 Voice ID，临时参考录音由官方工具单独操作。
- 蓝牙和 USB 设备真实插拔、可听音质、扬声器实际首音与尾音。Windows 接口测试使用静音输出。
- 同会话 Worker 崩溃后的水印续接。目前在故障时收敛到 ERROR，下一次手动开始重新建立基线。
- 生产数据的增量性能和手机到扬声器的端到端延迟。模拟 SQLite 数据只用于调度策略比较。
