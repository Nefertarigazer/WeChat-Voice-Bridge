# 微信语音桥 · 使用说明

软件里的「使用说明」页面和这份文档内容一致。三步就能用起来，其余的用到再看。

## 快速开始

### 1. 打开电脑微信，确认版本

登录电脑微信。版本号在微信左下角「≡ → 设置 → 关于微信」里，要在下表的范围内。微信的数据目录软件会自己找到。

| 微信版本 | 能否使用 |
| --- | --- |
| 4.2.0.52 | 支持，已实测 |
| 4.1.11 至 4.2.0.52 之间的其他版本 | 支持 |
| 4.1.11 之前，或 4.2.0.52 之后 | 不支持，打开时会提示更新语音桥 |

### 2. 添加语音服务和音色

声音由你选的语音服务合成。在「设置 → 语音服务」添加一家，填入它的 API Key（每家都附有去哪里获取的链接）；再到「音效」添加一个音色，试听一句。

| 类别 | 包括 |
| --- | --- |
| 主流厂商（填 Key 就能用） | Fish Audio（免费 · 🌐）、OpenAI（🌐）、ElevenLabs（🌐）、Azure 语音服务（免费）、Google Gemini（免费 · 🌐）、火山引擎 · 豆包语音、阿里云百炼、MiniMax（国内）、MiniMax（国际）、硅基流动 SiliconFlow、阶跃星辰、智谱 GLM-TTS、微软 Edge 朗读（免费，不用 Key） |
| 通用协议（接其他厂商或网关） | OpenAI 兼容接口、自定义 HTTP 接口 |
| 自建模型（在自己电脑上运行，免费） | GPT-SoVITS、fish-speech / OpenAudio、Kokoro-FastAPI、LocalAI |

🌐 在中国大陆需要海外网络；「免费」表示有免费额度，或完全免费。

### 3. 添加联系人，开始监听

在「首页」点「＋ 添加」，搜索并选中联系人，再给他选一个音色。点「开始」，等左下角变成「正在监听」，让对方发一条消息试试。

- 只读开始以后对方新发来的消息，以前的不会补读。
- 没有声音，或者声音太小：到「音效」选输出设备、调音量。

## 常用功能

- **提示词**：读消息之前先报名字，比如“小林说：……”。在联系人卡片上选。
- **多人朗读**：最多 8 人，各用各的音色；几个人同时来消息时排队，依次读。
- **隐私模式**：只说“微信来消息了”或一句暗语，不读内容。在联系人卡片上打开。
- **提醒模式**：消息没回，就按设定的间隔再提醒你；回复了或点「✓ 已读」就停。
- **词库**：改某个词的读法，比如把缩写读成全称、把表情读成文字。
- **外观**：浅色、深色或跟随系统；主题色有默认、浅绿、浅粉、浅蓝。在「设置 → 外观」里换。

## 遇到问题

- **没有朗读**：先看左下角是不是「正在监听」。软件只读开始以后、所选联系人新发来的消息，你自己发的不读。
- **提示版本不支持**：电脑微信的版本不在上面的表里，软件打开后会弹一个提示框。框里主按钮是「更新语音桥」：点它就在框里检查、下载并重启安装，装完再重新开始监听。提示框右上角的 × 是退出应用；如果已经点了「更新语音桥」或「更新微信」，关闭则不会退出。「更新微信」只在微信低于 4.1.11 时出现；微信版本比支持范围新时不会出现，那说明语音桥还在适配，等新版本发布即可。
- **合成失败**：401、403：Key 填错了或没有权限。402 或「余额不足」：去服务商那里充值。429：请求太快，稍等再试。带 🌐 的厂商要在海外网络下使用。
- **听不到声音**：检查「音效」里的输出设备和音量，再看看 Windows 的音量和音量合成器有没有把它静音。

## 隐私

消息只在这台电脑上读取，软件不收集你的聊天。朗读时，要读的文字会发给你选的语音服务；用自建模型则不出本机。API Key 用你的 Windows 账户加密保存在本机。请只添加同意被朗读的联系人。
