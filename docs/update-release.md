# 微信语音桥 1.3.0 软件更新

打开「高级 → 软件更新」可手动检查。程序启动时也会检查一次。左下角的「更新」只在发现新版后显示，点击可进入软件更新卡片并开始下载。下载通过大小和 SHA-256 校验后，可点击「重启安装更新」。监听或播放中需要再次确认。

1.2.0 还没有更新入口。首次升级需要关闭旧程序，然后把 1.3.0 ZIP 解压到有写权限的独立程序目录，运行 `WeChatVoiceBridge.exe`。以后可通过 1.3.0 的更新入口接收更高版本。

## 文件改动

- `Directory.Build.props` 将版本升至 1.3.0，客户端从生成的程序集元数据读取版本。
- `MainWindow.xaml` 新增高级页更新卡片及左下角有更新时才显示的入口。
- `MainWindow.xaml.cs` 在主窗口接入更新界面初始化与退出协作。
- `MainWindow.Updates.cs` 管理检查、下载、取消、校验反馈和重启确认。
- `App.xaml.cs` 分流后台安装助手入口，并把重启结果传给主窗口。
- `UpdateProcess.cs` 启动暂存的助手，等待指定旧进程退出，随后启动新版程序。
- `UpdateManifest.cs` 校验六个清单字段、下载地址和语义版本。
- `UpdateClient.cs` 发起 HTTPS GET、报告下载进度并校验字节大小与 SHA-256。
- `UpdateInstaller.cs` 限制解压路径，在覆盖前备份涉及的旧文件并在失败时回滚。
- `UpdateTests.cs` 覆盖版本比较、清单、下载、暂存和回滚。
